## What this is

A static website that explains and compares the Week 1 NLP curriculum:

- **Text Preprocessing** — sentence segmentation, tokenization, case normalization, stop-word removal, stemming, lemmatization, noise removal, text cleaning
- **Feature Engineering** — Bag of Words, N-Grams, TF, IDF, TF-IDF
- **Language Representation** — One-Hot Encoding, Word Embeddings, Word2Vec, FastText, Contextual Embeddings
- **Language Models** — Statistical, Neural, and Transformer-based models

It also includes the required Comparative Analysis tables, Workflow Diagrams, Real-World Applications, Research & Industry Insights, a Sustainability & Societal Impact write-up, and the group's Contribution Matrix.

## How to view it locally

No build step is needed — it's plain HTML/CSS/JS.

1. Download or clone the repo.
2. Double-click `index.html`, or right-click → "Open with" → your browser.

(Optional, for a local server instead of opening the file directly: run `python3 -m http.server` inside the folder, then visit `http://localhost:8000`.)
